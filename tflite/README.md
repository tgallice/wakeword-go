# tflite

Go bindings for the TensorFlow Lite FlatBuffers schema, generated by `flatc`. No logic lives here.

- Schema: `schema.fbs` from TensorFlow tag `v2.18.0`, path
  `tensorflow/compiler/mlir/lite/schema/schema.fbs` (the schema moved there in 2.18; it is the
  same version the `tflite` Python package 2.18.0 used by `tools/oracle/` is generated from).
- Schema sha256: `da73b89f169b80d40b49e8131092c0d122d3306f24d2269a36c50b8c2d22991c`
- flatc version: `25.12.19`
- Runtime dependency: `github.com/google/flatbuffers/go` (pure Go).

Regeneration, from this directory:

```bash
curl -fsSL -o schema.fbs \
  https://raw.githubusercontent.com/tensorflow/tensorflow/v2.18.0/tensorflow/compiler/mlir/lite/schema/schema.fbs
flatc --go --gen-onefile --go-namespace tflite -o gen schema.fbs
mv gen/schema_generated.go schema_generated.go && rmdir gen
```

The generated accessors do not verify the buffer. Corrupted input can panic inside them;
`runtime.Load` recovers from that and returns an error.
